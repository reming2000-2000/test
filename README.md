# 見積計算ツール / ESTIMATE

設備工事等の見積を、その場で計算する静的Webアプリです。日本語・PC／スマートフォン対応。実行時の依存パッケージ、ビルド、ログイン、サーバー処理は不要です。

## 起動

`index.html` をブラウザで開いてください。テキストの自動コピーはブラウザによりHTTPSまたはlocalhostが必要です。コピーできない場合は選択用テキスト欄が表示されます。

ローカルHTTPで確認する場合：

```sh
cd /workspace/test
python -m http.server 8000 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:8000` を開きます。公開する場合は `index.html`、`styles.css`、`calc.js`、`app.js` の4ファイルを同じディレクトリに静的配置してください。

## 使い方

1. 部品代、作業人員、部品送料を入力します（初期値は0）。
2. 必要な場合だけ標準設定を開いて掛率・単価を変更します。
3. 費目ごとの採用額を入力します。空欄は標準額を使用し、明示的な0は0円を採用します。
4. 任意で100文字までの補正理由・メモを入力します。個人情報や案件識別情報は入力しないでください。
5. 計算結果を確認し、必要な場合のみPNG保存またはテキストコピーを実行します。

基本入力や設定を空欄にすると0として扱います。不正値は個別エラーを表示し、計算への代入値を0として画面を維持します。不正値がある間は出力・プレビューを無効にします。修正後に正しい値から即時再計算します。

## 計算ルール

内訳およびPNG・テキスト出力の表示順は、部品代 → 交換作業費 → 消耗資材費 → 撤去品引取費 → 部品送料・運搬交通費 → 養生・安全対策費です。「送料」は「部品送料・運搬交通費」に改称しています（基本入力の部品送料はそのままです）。

- 部品代：基本入力の部品代。
- 消耗資材費・撤去品引取費・養生安全対策費：**基本入力**の部品代 × 対応率（初期値5%、3%、2%）。部品代の採用額を変更しても標準額の基準は変えません。
- 交換作業費（売価）：作業人員 × 売価単価（初期値58,000円／人）。
- 交換作業原価（参考）：同じ作業人員 × 固定原価単価36,000円／人。売価と同じ算定根拠欄に表示し、見積総額には加算しません。採用額の変更によって原価は変化しません。
- 部品送料・運搬交通費：同じ作業人員 × 作業員送料単価（4,000円）＋ 部品送料。
- 小計：6費目の採用額、または空欄の場合は標準額の合計。
- 諸経費：採用小計 × 諸経費率（10%）。
- 法定福利費：採用交換作業費 × 法定福利費率（16.315%）、**1円未満切り捨て**。
- 見積金額（税別）：小計 ＋ 諸経費 ＋ 法定福利費。消費税は計算しません。
- 標準見積総額：現在の設定値を使い、採用額を一切反映しない場合の総額。諸経費・福利費も標準額から計算します。
- 部品代比：各費目の計上額 ÷ 基本入力の部品代。分母0の場合は「—（基準額0円）」を表示します。
- 標準との差額が0でない費目を変更一覧に表示します。同額の採用額は変更として数えません。自動再計算される諸経費・福利費は6費目の変更一覧には含めませんが、総補正額に含めます。

金額・単価は小数2桁、作業人員・率は小数3桁を受け付けます。1.5人などの小数人員を、交換作業費・送料・原価に共通で使用します。金額上限は1兆円、作業人員上限は100万、率上限は1,000%です。負数、指数表記、不正なカンマ、上限超過は受け付けません。全角数字は半角に正規化します。フォーカス中はカンマなし、離れると3桁区切り表示になります。

金額計算にはBigIntによる小数12桁の固定小数点を使用します。上記の入力桁数内で、法定福利費以外の計算では小数円を丸めず保持・表示します。比率表示だけ四捨五入します（費目標準比1桁、部品代比・総額標準比2桁）。採用入力は小数2桁までです。

## 保存用サマリー

画面のスクリーンショットではなく、専用確認シートを生成します。基本条件、**変更後の標準設定値**、見積内訳、交換作業費の売価・参考原価、標準総額との比較、変更費目の標準→採用・差額・比率・メモを含みます。変更していない費目のメモも別欄に出力します。

- PNG：Canvasで幅2,240pxの白背景画像を生成。内容に応じて高さを調整し、メモを自動折り返しします。端末によってダウンロードできない場合は表示画像の長押し保存を利用できます。
- コピー：同等内容のプレーンテキスト。Clipboard APIを使い、利用不可／権限拒否時には手動コピー欄を表示します。
- 出力日時：端末時刻を基に日本時間（Asia/Tokyo）、秒付きで表示。ファイル名は `estimate_YYYYMMDD_HHmmss.png`。

## プライバシー

入力はページのメモリ内のみ。ストレージ、Cookie、データベース、外部API、解析、外部CDN、Webフォントは使用しません。再読み込み・ページ再表示で初期値に戻します。画像・テキスト出力は明示的なボタン操作時のみ端末内で行います。静的配信時にHTML/CSS/JS自体を取得する通信は発生しますが、見積の入力や出力内容は送信しません。CSPでも `connect-src 'none'` を指定しています。

## Excel確認結果と変更点

添付「見積計算シート_改良版.xlsx」は「見積計算」1シート、29行×7列。上部に案件入力と標準設定、中央に標準額・採用額・差額・計上額・メモの7列表、下部に補正状況がありました。

最新の依頼仕様を優先して以下を変更しています。

- 後続の依頼に従い、交換作業人工と作業員人数を「作業人員」に統合し、小数3桁まで入力可能に変更。交換作業費と送料は同じ値で計算します。
- 交換作業費の原価36,000円／人を固定の参考情報として併記。画像・テキストにも出力。

- 件名欄を削除。
- Excelでは採用部品代を関連費目の標準額の基準に使用。Web版は基本入力の部品代を使用。
- Excelでは法定福利費が未切り捨て。Web版は1円未満切り捨て。
- 諸経費・法定福利費は採用額の手動上書きを設けず自動計算。
- 標準比・部品代比、変更一覧、レスポンシブカード、PNG／テキスト出力を追加。

## テスト

計算テスト（Node.js、追加インストール不要）：

```sh
node tests/calc.test.cjs
```

ブラウザ統合テスト（開発検証用のみ、Python Playwright・Chromiumと上記HTTPサーバーが必要）：

```sh
python tests/browser_test.py
```

現在の仕様での期待値（人員統合により旧仕様の「6人工・3人」とは送料・総額が変わります）：

| 条件 | 小計 | 諸経費 | 法定福利費 | 税別総額 |
|---|---:|---:|---:|---:|
| 部品850,000円・作業人員6人・部品送料20,000円 | 1,327,000 | 132,700 | 56,776 | 1,516,476 |
| 消耗資材費のみ70,000円を採用 | 1,354,500 | 135,450 | 56,776 | 1,546,726 |
| 部品850,000円・作業人員1.5人・部品送料20,000円 | 1,048,000 | 104,800 | 14,194 | 1,166,994 |

2行目の差額は＋27,500円、標準比＋64.7%、部品代比8.24%、総補正＋30,250円です。

実ブラウザ検証はChromiumで実施。検証環境の管理ポリシーで `file://` が禁止されているため、HTMLの直接起動は未検証です。HTTP経由での利用を推奨します。実機iOS/SafariおよびWindows各ブラウザの検証は含みません。モダンブラウザ（BigInt・Canvas対応）が必要です。

将来の小規模な拡張候補：印刷レイアウト、任意の端数処理設定。今回の版には含めていません。

作業人員1.5人の場合：交換作業売価87,000円、参考原価54,000円、送料26,000円（部品送料20,000円を含む）です。
