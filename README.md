# CAT — Calculation Assistant Tool

設備工事等の見積を、その場で計算する静的Webアプリです。日本語・PC／スマートフォン対応。実行時の依存パッケージ、ビルド、ログイン、サーバー処理は不要です。

## 起動

`index.html` をブラウザで開いてください。テキストの自動コピーはブラウザによりHTTPSまたはlocalhostが必要です。コピーできない場合は選択用テキスト欄が表示されます。

ローカルHTTPで確認する場合：

```sh
cd /workspace/test
python -m http.server 8000 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:8000` を開きます。公開する場合は `index.html`、`styles.css`、`calc.js`、`portable.js`、`app.js`、`cat.css`、`cat.js` の7ファイル、`manifest.webmanifest`、`assets/cat-sprites.png`、`assets/cat-icon.png`、`assets/cat-icon-192.png`、`assets/cat-apple-touch-icon.png`、`assets/cat-favicon.png` を、フォルダー構成を保って静的配置してください。

## 名前・アイコン・更新番号

- 表示名は **CAT**、正式名称は **Calculation Assistant Tool** です。タブ名・ホーム画面の短縮名はCATに統一し、正式名称は画面内に表示します。
- favicon・Appleのホーム画面アイコン・Web App Manifest・ヘッダーで同じローカルの猫アイコンを使います。配信先が `/test/` でも動作するよう、リンク・manifestの開始URLとscopeを相対指定しています。
- iPhoneでは共有メニューの「ホーム画面に追加」、Androidではブラウザメニューの「ホーム画面に追加」などで登録します。既存のブックマークやホームアイコンの名前・画像が更新されない場合は、登録し直してください。端末側のキャッシュによって反映に時間がかかる場合があります。
- ホーム画面追加用のメタデータのみを加えており、サービスワーカー・オフラインキャッシュ・入力保存は実装していません。
- フッターに **CAT v1.7.0** を表示します。CATへの改称版v1.0.0からの番号です。今後公開する修正ではこの番号を更新してください。軽微な修正はパッチ番号（例：v1.0.1）を上げ、変更したCSS/JS/manifest/アイコンのクエリ文字列も更新してキャッシュを切り替えます。
- 旧名 `NekoAssist 簡易シート v1` は過去のメモを読み込むための識別子として維持します。この旧形式と従来のコンパクト形式も引き続き読み込めます。

## 使い方

1. 部品代、作業人員、部品送料を入力します（初期値は0）。
2. 必要な場合だけ標準設定を開いて掛率・単価を変更します。
3. 費目ごとの採用額を入力します。空欄は標準額を使用し、明示的な0は0円を採用します。
4. 任意で100文字までの補正理由・メモを入力します。個人情報や案件識別情報は入力しないでください。
5. 計算結果を確認し、必要な場合のみPNG保存またはテキストコピーを実行します。

基本入力や設定を空欄にすると0として扱います。不正値は個別エラーを表示し、計算への代入値を0として画面を維持します。不正値がある間は出力・プレビューを無効にします。修正後に正しい値から即時再計算します。

## 簡易版のコピー・条件の読み込み

簡易コピーは、見積総額・基本条件／掛率／単価／採用額・メモ／諸経費モードの基本5行に、追加項目や連動設定を必要に応じて加えます。明示的に入力した0円と標準額と同額の採用額も記載し、固定状態を復元します。空欄の採用額は標準として復元します。追加行の定義には標準額とタグを記載し、固定採用額や補正メモは採用行に残します。

資材・撤去・養生は、見積計上額が標準額と異なるときだけ、`資材=314,400(2.71%)` のように基本入力の部品代に対する実質掛率を添えます。小数は最大2桁で、部品代が0円なら省略します。括弧内の値は見積を読むための表示で、取込時は採用額・設定掛率・連動の元の金額と基準額を使います。

追加項目を諸経費の直前に並べた通常順なら、追加定義の順序から復元できるため「内訳」行を省きます。それ以外の並び順は「内訳」行で保持します。読み込み時は見積総額を検証し、「内訳」行がある場合は各行の金額も照合します。提示例では385文字から292文字になりました。内訳の省略がない場合は、実質掛率の分だけ長くなります。

「結果を持ち出す」の **簡易版をコピー** で、基本条件、全掛率・単価、各採用額、メモ、追加項目、諸経費モード、税別総額を短いテキストにまとめます。原価の説明や標準比較の詳細は省略します。従来の確認シート・PNG出力も利用できます。

後日、画面上部の **簡易版から計算条件を読み込む** を開き、コピー全文を貼り付けます。「内容を確認」で反映後の金額・設定・固定項目を確認してから「この条件を反映」を押します。確認中は現在の入力を変更しません。形式違い、項目不足・重複、範囲外の値、計算総額の不一致は反映を拒否します。新しい5行形式と従来の `NekoAssist 簡易シート v1` 形式を読み込めます。画像や任意の文章は読み取りません。

- 初期選択の「補正した経費を、採用時の割合で連動させる」は、採用額を指定した消耗資材費・撤去品引取費・養生費の **基本入力の部品代比** と、手動諸経費の **小計比** を引き継ぎます。部品追加後も同じ割合で再計算できます。
- 例えば部品85万円に対して消耗資材費7万円なら、部品170万円で14万円。内部は元の金額の比（分子／分母）を使い、画面に表示する丸めた％を計算に使用しません。金額の精度は既存計算と同じ小数12桁固定小数です。
- 基準額が0円なら比率を作らず固定額で復元します。部品代・交換作業費・送料・追加項目の手動採用額も固定で、プレビューに明記します。採用額が空欄の費目は元の設定率・単価で計算します。
- チェックを外すと元の入力・連動状態をそのまま復元します。既に引継率連動で出力したテキストは、その連動も復元します。諸経費の端数付き自動連動はそのまま維持します。
- 引継率で連動する採用欄には状態を表示します。採用額の手入力で固定、空欄で標準に戻ります。対応する標準設定の率を変更した場合も、引継率を解除して新しい設定率を適用します。一括端数調整でも復元した固定額と引継率連動は保持します。標準額を再採用したい場合は、その採用額を空欄にしてから調整します。
- メモ・追加名称は引用符をエスケープし、DOMにはテキストとして反映します。簡易版は追加100項目・50,000文字までです。値引計算は試算のため含めません。
- コピー拒否時は手動コピー用欄を表示します。読み込みもすべてブラウザ内で完結し、保存・外部送信はありません。読み込み用テキストもリセット・再読み込みで消えます。テキストを残す場合はユーザー自身で保管してください。

## 部品代に連動する掛率と参考表

基本入力の部品代（採用部品代ではない）を変更すると、標準設定の消耗資材費率・撤去品引取費率が次のとおり連動します。既存の計算式・端数ボタン・採用額・諸経費モード・法定福利費・原価計算は引き続き使用します。

| 部品価格 | 消耗資材費率 | 撤去品引取費率 |
|---|---:|---:|
| 50万円以下 | 7% | 5% |
| 50万円超〜100万円未満 | 5% | 3% |
| 100万円以上〜300万円未満 | 3% | 2% |
| 300万円以上 | 2% | 1% |

- 原資料で重複する50万円ちょうどは「50万円以下」を優先します。100万円・300万円ちょうどはそれぞれ上の価格帯へ切り替わります。
- 部品代0円・空欄・不正値では掛率を書き換えません。初回・リセット直後の0円では従来の初期値5%・3%を表示し、有効な正数の入力を待ちます。
- 率を手入力すると、その項目だけ手動保持になります。部品代変更時も手動率・採用額・メモを保持します。「2項目を部品代に連動させる」で両方の標準掛率を自動に戻せます。採用額・引継率による補正は引き続き優先されます。
- 簡易コピー（新旧形式）の読み込み時は、過去条件の再現を優先し、復元した両掛率を保持します。部品代変更によって資料の基本掛率に上書きしません。自動に戻す場合は同ボタンを使用します。出力には実際の掛率を記載します。
- リセット・再読み込みで手動／復元状態を消し、自動入力待ちに戻します。
- 「部規定の参考表」は標準設定・端数調整の近くで開けます。基本掛率、管理会社費用による補正例、交通費・部品送料、廃油処理、宿泊費、現場管理費・安全対策費、諸経費・法定福利費の目安をまとめています。新たな費目や契約区分入力は追加しません。
- 原資料の会社名・運搬経路の固有地名・顧客区分の固有名称は掲載せず、参考価格と適用条件を記載します。運搬費は特定条件の目安であり、実条件で確認します。
- 原資料に明示のない管理会社費用7%未満・部品100万円未満の補正率、諸経費1,000円以上10,000円未満の丸めは推測せず、要確認と記載します。諸経費の切り上げや交通費の車両別計算は参照用で、CATの現行計算方法を使います。

## 追加項目のタグ・並べ替え（v1.1.0）

通常の入力画面は従来どおりです。02の「タグ・順番を編集」を開くと、すべての費目に移動用のつまみと上下ボタン、追加項目に費目タグの選択欄が現れます。「編集を終える」で操作欄を閉じます。設定したタグと順序はそのまま計算・出力へ反映されます。

- 追加項目のタグ：未分類（初期値）、部品代、交換作業費、消耗資材費、部品送料・運搬交通費、撤去品引取費、養生・安全対策費。同じタグ・同じ項目名を複数行で使えます。既存行の計算上の分類は従来どおり固定です。
- **交換作業費タグ**は法定福利費の計算対象です。既存交換作業費の見積計上額＋タグを付けた追加作業費の見積計上額を合計し、その合計×法定福利費率を1円未満切り捨てします。個別に切り捨ててから合計はしません。例：116,000＋58,000＝174,000円、×16.315%→28,388円。
- 追加行で採用額を指定した場合はその額を使い、0円も有効です。タグ変更・金額変更・削除で即時再計算します。法定福利費の参考原価（×0.66）と標準見積総額の法定福利費も、同じ対象を基準として計算します。
- 交換作業費以外のタグは分類用です。追加行の金額は手入力のままで、部品代比の自動計算・基本入力の人員・送料・追加行の参考原価を推定しません。基本入力の部品代は従来どおり標準掛率の基準で、追加行の部品代タグでその基準額は変えません。
- 追加費用は、タグにかかわらず従来どおり小計と諸経費の基準に含まれます。諸経費は集計費目のため追加行の分類タグには含めません。費目が並び替わっても計算はID・タグで判定し、諸経費の二重計上は行いません。
- 既存行・追加行・諸経費の行を自由に並べ替えられます。PC・スマホとも⠿のドラッグに対応し、画面端では自動スクロールします。↑↓ボタンはタップ・キーボードでも操作できます。ドラッグ中はEscapeまたはタッチキャンセルで移動前の順番へ戻ります。
- 小計・法定福利費・最終合計は、集計欄として最後に表示します。「＋ 項目を追加」は諸経費の直前に置き、新しい行も現在の諸経費の直前に追加します。
- 「タグ・順番を編集」を開いている間は、先頭・費目の間・末尾に「＋ ここに追加」が表示されます。押した位置に行を挿入し、名称欄にフォーカスします。追加時のタグは未分類です。位置を変えてもタグや金額は保持されます。
- 並べ替え・タグ変更は端数調整の取り消しを解除します。コピー済みの目印は実際のコピー文字列が変わった場合だけ解除します。費目名・採用額・メモは行を移動しても保持します。
- 簡易コピーは、通常の標準順・追加なしなら日時なしの5行形式です。追加項目の定義だけで表示順を復元できない場合は、画面順に並んだ「内訳」行を加えます。追加行の定義にタグを記載し、同名行も別の行として識別します。復元時はタグ・順番・標準額・採用額・メモを引き継ぎます。
- 新旧の簡易コピーは引き続き読み込めます。タグ・順序のない旧形式は追加行が未分類で、従来の標準順になります。不明タグ、内訳の重複・項目不足・金額不一致は反映前に拒否します。詳細テキスト・PNGも画面の費目順にし、追加作業費がある場合は法定福利費の算定対象を明示します。
- リセット・再読み込みでタグ・順序を消去して従来の初期状態へ戻します。端末内・サーバー側の保存や外部送信は追加していません。

## 社内見積データ取込

画面上部の「社内見積データを読み込む」に明細全体を貼り付けると、費目別の集計と部品代比が表示されます。通常はそのまま「CATに反映」で完了します。売価が読めて分類が曖昧な明細は「要確認」で振り分けます。売価が読めない行は「形式を確認してください」に表示します。「原文を表示」でコピーした行を確認し、貼り付け直すか、対象外と確認した行だけを除外できます。「明細と振り分け先を確認・変更」を開くと、分類済みの明細も変更できます。既存のCAT入力がある場合は、反映ボタンを押したときに置き換えを確認します。

対応するコピー形式：

- 売価行（番号／区分／品名／備考／数量／単価／金額…）と原価補助行が交互に並ぶタブ区切り。売価行の直後にある、番号・型式・単位から始まる補助行は、単位・原単価・原価の並びで識別します。形式が重なって売価行の可能性がある場合は確認対象にします。「FREE」と括弧付きの見出し名、空の数量・単価、0円の金額がそろった区分見出しと、それに続く番号・空欄・0の補助行を集計から省きます。小計後のゼロ行、値引後の `式・空欄・0` も補助行として扱います。
- 「品名（費目名・名称など）」と「売価金額（金額・売価など）」の見出しがあるTSV。区分・番号・数量・単位・備考を併用でき、引用符付きセル・改行入り備考にも対応します。
- 同様の見出しを持つ `|` 区切りの表、または2個以上の半角スペースで列が分かれた表。列を確定できない行は未読取として表示します。

ヘッダーのない任意の表、CSV、単一スペースの羅列、HTMLそのもの、Excelファイル・画像・PDFの読取は対象外です。200,000文字・2,000行まで。金額はCATと同じ1兆円・小数2桁までで、合算した費目の上限も検証します。追加項目は100件・名称は改行なし40文字までです。未読取行は黙って捨てず、貼り付け直すか対象外を選ぶまで反映できません。未読取金額があれば元明細合計は「確認できません」と表示します。

分類と反映：

- `FREE部品` などの部品区分を優先し、それ以外は名称の具体的なキーワードで分類します。「経費」の区分だけでは諸経費にしません。消耗資材・諸材料、交通費・輸送費・送料・運搬費、撤去品引取・撤去処分、養生・安全対策、交換作業費、諸経費、法定福利費などを判定します。「現場諸材料、工事機材費」は消耗資材費に分類します。「工事機材費」単独や複数費目のキーワードが混在する明細は、確認対象です。
- 部品は合算して基本入力へ反映し、既存費目の売価は合算して固定採用額へ反映します。数量×単価をさらに加算したり、備考から金額を拾うことはしません。原価は参考原価欄へ移しません。CATの原価式を維持します。
- 作業人員は、明示された人工・人日や備考の「13日×3名」のような式から根拠が明確な場合に自動採用します。交換作業費の直後にある原価補助行の備考「12人×58,000」のように人数と金額が明記されている場合も、人数の根拠に使います。根拠が足りない場合や人工の表記が食い違う場合は手動入力が必要です。自動採用した値も「作業人員を変更」から修正できます。
- 部品送料の基本入力を0円にして送料の元売価を採用するため、作業員交通費を二重加算しません。元データにない既存費目は0円で固定します。諸経費は手動固定とし、自動再計算による元金額の変更を防ぎます。これらの採用額は一括端数調整でも保護されます。
- 試運転調整費などは追加項目へ反映し、法定福利費対象は初期状態で対象外です。含める場合のみ確認画面でチェックします。元の備考を補正メモへ自動転記しません。
- 現在の標準設定・単価と自動掛率／手動掛率の状態を維持します。部品代に自動連動中の2率だけは新しい部品代の区分に連動します。取込元に合わせて率を逆算する処理はありません。

法定福利費は追加項目にせず、元金額とCATの自動計算額を比較します。値引・負額はCAT費目へ押し込まず比較用に扱います。名称だけでは値引と判定できない負額や正数表記の値引は、手動確認対象です。比較欄には元データの最終金額、CATの比較用金額、差額を表示します。元データに合計の記載がない場合は、読み取れた明細から算出します。値引、法定福利費、元の小計、除外項目や不一致の詳細は「比較の詳細」で確認できます。未確認項目が残っている間は、比較額が一致しても反映できません。取込元の小計とCATの小計は集計範囲が異なる場合があります。

架空名称の提供形式サンプルで確認した結果：部品11,692,000円、作業費2,262,000円、追加754,000円、資材435,000円（部品代比3.72％）、送料650,000円、養生260,000円、諸経費1,605,300円。元小計17,658,300円、法定福利費369,045円、CAT税別総額18,027,345円、比較用値引−27,345円、比較用値引後18,000,000円です。CATのコピー・PNG・簡易出力は従来どおり値引前の計算結果です。

社内見積を反映した後は、標準設定の下に「取込後の再計算」が表示されます。消耗資材費・撤去品引取費・養生・安全対策費・諸経費から対象を選び、変更前・変更後・差額を確認して「標準計算に戻す」を押します。資材・撤去・養生は現在の部品代と掛率、諸経費は追加項目を含む採用小計と諸経費率に連動します。取込元に金額0円の明細があった場合と、明細がなく0円で取り込まれた場合を区別します。取込元の区別と取り消しは現在の画面内だけで有効です。

解析・確認・反映はブラウザ内のみで行い、サーバー送信・保存・分類学習・自動ログ出力はしません。反映時は貼付明細と分類表を消去し、数値の比較だけ一時表示します。次のCAT編集・リセット・再読み込みで比較も消去します。簡易出力形式・取込互換性、計算式・掛率・端数処理は変更しません。会社システムへの書き戻し機能は追加していません。

- 交換作業費の見積計上額が既存の参考原価（作業人員×36,000円、1円未満切り捨て）未満なら、原価欄の下に「参考原価を下回っています」と表示します。同額以上・原価0円で計上額0円・入力エラー中は表示しません。他の費目や追加行は対象外です。薄い黄褐色の小さな注意表示で、03の標準差による赤枠とは区別します。計算・コピー・出力は止めず、注意文を保存用サマリーへ追加しません。

## 標準との差が大きい項目の表示（v1.1.1）

03の変更カードは、現在の標準額と見積計上額の差額率が増額・減額どちらも **1%以上** で、差額の絶対値が **100円以上** の場合に控えめな赤枠と「標準比…・要確認」を表示します。標準額が100万円以上の費目は金額条件を1,000円以上とします。端数調整と同じ単位を基準にするため、1,550円→1,500円のように差額率が1%以上でも差額50円なら従来の表示です。

判定はBigIntで丸め前の値を比較し、画面の丸めた％表示は使いません。1%未満でも丸め表示で1.0%となる場合があります。標準額0円では割合を計算せず、100円以上の追加を「標準額0円・要確認」と表示します。不正な入力がある間は確認表示を抑え、従来の入力エラーを優先します。

これは金額を見直す目安で、意図した補正も対象になります。メモの有無によらず同じ条件で判定します。採用額・掛率・諸経費・法定福利費などの計算、コピー内容、PNG・メモの形式は変更しません。部品代や設定を変更した後も、現在の標準額に対して即時に判定し直します。

## 入力・調整・転記を助ける表示

- 各行に採用額の状態を「自動計算」「手動固定」「端数調整済み」「引継掛率で連動」などと表示します。明示的な0円・標準額と同額でも、固定していれば固定中と表示します。諸経費の連動状態は費目名の下に表示します。端数調整で保持した費目は「端数調整の対象外だった費目」から確認できます。
- **コピー済みの目印**：金額・算定根拠・参考原価それぞれのコピー成功後に小さなチェックを表示します。貼り付け完了を意味する表示ではありません。コピー対象の文字列が変わった場合だけ解除します（参考原価の切り捨て結果が同じならそのチェックは保持）。メモの変更など対象文字列が変わらない操作では残ります。不正入力中は解除し、リセット・読み込み・再読み込みでも消えます。
- **コピー処理中の操作**：非同期コピーが終了する前に金額が変わったり、行を削除・リセットしたりした場合に、現在の値へ誤ったチェックや古い成功通知を付けません。コピー拒否時は従来の手動選択欄を表示し、チェックを新たに付けません。簡易コピーの処理中に入力が変わった場合は、変更前の簡易版をコピーした旨を通知します。
- 端数調整の後は「調整前に戻す」、取込後の再計算の後は「再計算前に戻す」を表示します。最後に行った種類の操作について、採用額・連動状態・取込額の固定表示を戻せます。端数調整を続けて押した場合は、最初の調整前へ戻れます。基本入力・設定・採用額・メモ・追加項目の編集、条件の読み込みやリセットを行うと取り消しを解除します。コピー・プレビュー・値引試算・表示の開閉では解除しません。
- **売価・原価の区別**：見積計上額のコピーボタンは薄い青、参考原価は薄いグレーで統一します。文字ラベルと読み上げ用ラベルも併用します。
- **標準設定の変更一覧**：消耗資材費・撤去品引取費は現在の部品価格帯の規定率、それ以外は従来の初期値と比較します。「規定5％ → 手動9％」などの差分を03の欄に表示し、画像・詳細テキストにも反映します。復元した値には「復元」と表示します。自動掛率の切替自体は手動変更の一覧に含めません。
- **簡易コピーのプレビュー**：「簡易コピーの内容を確認」を開くと、実際にコピーする5行形式と補足行を確認できます。入力・採用額・メモを変更すれば更新し、不正値がある間は確認を促す表示に切り替えます。簡易コピーとプレビューには出力日時を付けません。日時付きの旧簡易コピーも引き続き読み込めます。
- **Enterで入力移動**：見積フォーム・値引フォームそれぞれの、開いている編集可能な入力欄を順に移動します。Shift+Enterは前の欄へ移動します。数値の不正入力中は同じ欄に留まり、最後の欄ではフォーカスを外します。日本語IMEの変換確定・修飾キー・文章を貼るテキストエリア・ボタンのEnter操作は移動処理の対象外です。スマホでは対応ブラウザへ「次へ／完了」のヒントを出します。

## 計算ルール

内訳およびPNG・テキスト出力の表示順は、部品代 → 交換作業費 → 消耗資材費 → 部品送料・運搬交通費 → 撤去品引取費 → 養生・安全対策費 → 諸経費です。「送料」は「部品送料・運搬交通費」に改称しています（基本入力の部品送料はそのままです）。

- 部品代：基本入力の部品代。
- 消耗資材費・撤去品引取費・養生安全対策費：**基本入力**の部品代 × 対応率（消耗資材費・撤去品引取費は上記価格帯で連動、養生費は初期値2%）。部品代の採用額を変更しても標準額の基準は変えません。
- 交換作業費（売価）：作業人員 × 売価単価（初期値58,000円／人）。
- 交換作業原価（参考）：同じ作業人員 × 固定原価単価36,000円／人。売価と同じ算定根拠欄に表示し、見積総額には加算しません。採用額の変更によって原価は変化しません。
- 部品送料・運搬交通費：同じ作業人員 × 作業員交通費単価（4,000円）＋ 部品送料。
- 小計：6費目と追加項目の採用額、または空欄の場合は標準額の合計。
- 諸経費：採用小計 × 諸経費率（10%）を標準額とし、採用額で任意に上書きできます。小計には諸経費を含めず、見積総額に採用諸経費を1回だけ加算します。諸経費の行は小計の上に表示します。
- 法定福利費：既存交換作業費と交換作業費タグの追加行の見積計上額合計 × 法定福利費率（16.315%）、**1円未満切り捨て**。
- 法定福利費原価（参考）：切り捨て済みの法定福利費 × 0.66。参考原価は1円未満を切り捨てて表示し、見積総額には加算しません。交換作業費の採用額・法定福利費率の変更にも追従します。
- 見積金額（税別）：小計 ＋ 諸経費 ＋ 法定福利費。消費税は計算しません。
- 標準見積総額：現在の設定値を使い、採用額を一切反映しない場合の総額。諸経費・福利費も標準額から計算します。
- 部品代比：各費目の計上額 ÷ 基本入力の部品代。分母0の場合は「—（基準額0円）」を表示します。
- 標準との差額が0でない費目を変更一覧に表示します。同額の採用額は変更として数えません。諸経費の手動変更も変更一覧・総補正額に反映します。法定福利費は交換作業費から自動計算します。

金額・単価は小数2桁、作業人員・率は小数3桁を受け付けます。1.5人などの小数人員を、交換作業費・送料・原価に共通で使用します。金額上限は1兆円、作業人員上限は100万、率上限は1,000%です。負数、指数表記、不正なカンマ、上限超過は受け付けません。全角数字は半角に正規化します。フォーカス中はカンマなし、離れると3桁区切り表示になります。

金額計算にはBigIntによる小数12桁の固定小数点を使用します。上記の入力桁数内で、法定福利費・参考原価以外の計算では小数円を丸めず保持・表示します。比率表示だけ四捨五入します（費目標準比1桁、部品代比・総額標準比2桁）。採用入力は小数2桁までです。

## 標準額の端数を一括調整

標準設定の直下にある「標準額の端数を整えて採用」で、標準額から採用額を一括入力できます。

- 100万円以上：1,000円単位で切り捨て（1,552,110 → 1,552,000）。
- 100万円未満：100円単位で切り捨て（155,211 → 155,200、15,521 → 15,500、1,550 → 1,500）。100円未満は0円です。
- 部品代以外の空欄、またはこの画面で前回一括調整した採用額を対象にします。追加費目にも対応します。手動入力済みの額（0円・標準額と同額を含む）、復元された固定額・割合連動は保持し、保持件数を通知します。部品代は常に対象外です。
- 一括調整した採用額を手動で編集すると、同じ金額を入力した場合も以後は保持します。採用欄を空欄に戻すと再び調整対象になります。基本条件・設定・メモの変更だけでは、一括調整した状態を解除しません。標準設定・基本入力・メモは保持します。
- 諸経費が通常の自動連動なら、従来どおり端数調整付き自動連動へ切り替わります。既に端数付き自動なら継続し、手動固定・復元した割合連動ならその状態を保持します。小計には保持した採用額も含め、法定福利費は対象作業費から再計算します。書き込む額が入力上限を超える場合は、全項目を変更せず説明を表示します。
- 調整前に戻すと、採用額・諸経費モードに加え、一括調整由来かどうかの状態も復元します。この区別は画面のメモリ内だけに保持し、簡易出力・取込形式や文字数は変えません。復元した過去の一括調整額は固定額として保護します。
- 参考原価はすべて1円未満を切り捨てます（交換作業費・法定福利費）。

## 総補正額の内訳（v1.2.0）

合計欄の「総補正額」をクリック／タップ（キーボードではEnter／Space）すると、費目の補正・諸経費の増減・法定福利費の増減・合計を表示します。初期状態・リセット・再読み込みでは閉じています。開閉は金額、取り消し、出力内容へ影響しません。

比較基準は、現在の基本条件・標準設定・追加費目を標準額で集計した補正前の見積です。直接費目の差額を合算し、法定福利費は標準の対象作業費合計に対する切り捨て後の額と比較します。標準諸経費は標準見積総額から標準小計と標準法定福利費を除いた額です。表示用の差額率や丸めた表示額は使わず、3項目の合計を既存の総補正額と一致させます。追加費目自体は従来どおり標準見積にも含み、その採用差額を補正として扱います。入力エラー中の内訳は「—」とします。

## 内訳の表示

主表は費目・算定根拠、標準額、採用額、見積計上額の4列です。計上額を強調し、標準額は控えめに表示します。採用額により差額が生じた行だけ、差額と標準比を表示し、補正理由の欄を自動で開きます。詳細は手動でも開閉できます。部品代比とメモ欄は詳細にまとめています。開閉しても入力済みのメモは保持され、画像・テキスト出力にも含まれます。リセット・再読み込み時は詳細も閉じます。

## 任意項目の追加

諸経費の直上にある「＋ 項目を追加」で費目を追加できます。名称（40文字まで、例：試運転調整費）と金額を入力し、必要なら採用額・メモも利用できます。名称未入力時は「追加項目1」などの仮名称を使用します。「削除」で取り除けます。

追加項目も小計・標準見積総額・現在総額・値引試算に含め、諸経費は追加分を含む小計から自動連動します。手動固定中なら変更確認を表示します。法定福利費の基準は交換作業費です。追加項目に参考原価率は自動設定しません。

追加項目は金額・根拠のコピー、端数調整、画像・テキスト出力に対応します。元の金額を標準額とし、採用額があれば上書きします。名称は文字として処理し、HTMLとして実行しません。保存はせず、全リセット・再読み込みで追加行も消えます。

## 諸経費の自動連動

- 初期状態「自動連動」：現在の採用小計×諸経費率で更新します。
- 自動連動中に端数調整ボタンを押した後「自動連動・端数調整」：他の費目・基本入力・率を変えるたび、諸経費も既存の切り捨て規則で再計算します。単に固定採用額を残す動作ではありません。
- 諸経費の採用額を直接入力すると「手動固定」。入力時の小計・率を記録し、変更されたら確認メッセージを表示します。コピー・保存用サマリーにも現状の固定額と注意を反映します。
- 「自動に戻す」または採用額を空欄にすると、直前の自動モード（通常または端数調整付き）へ戻ります。全リセット・再読み込みで通常の自動連動に戻ります。

## 値引計算（試算）

見積金額の直下に2つの独立した試算行があります。％入力から値引額（円・万円）と値引後の金額、金額入力から値引率と値引後の金額を計算します。基準は現在の税別見積総額で、採用額変更にも追従します。例：500,000円の5％引き→25,000円（2.5万円）引き・値引後475,000円。30,000円引き→6％・値引後470,000円。

％入力は0〜100％・小数3桁まで、金額は0〜見積金額・小数2桁まで。値引額は小数円も保持し、金額から求める率は小数2桁まで四捨五入します。見積0円のとき、金額からの率は「—」です。空欄は未計算として扱います。2行を合算したり互いに連動させたりしません。試算は内訳・原価・見積総額・保存用サマリーには反映しません。リセット・再読み込みで両方とも消えます。

## 参考原価の表示・コピー

消耗資材費・撤去品引取費・養生安全対策費・諸経費は、見積計上額×62％を参考原価として表示します（利益率＝利益÷売価＝38％）。採用額があればその売価を基準に計算し、1円未満を切り捨てます。例：売価100,000円→参考原価62,000円。参考原価は総額への加算項目ではありません。

交換作業費は作業人員×36,000円、法定福利費は現在の法定福利費×0.66の既存ルールを維持します。計6項目に同じ原価コピーアイコンを設け、クリックすると `62,000` のように単位なしでコピーできます。4費目の原価は画像・テキストの確認シートにも含めます。

## 社内システムへの転記

諸経費を含む7費目それぞれで、金額と算定根拠のすぐ横にコピーアイコンがあります。PCではマウスを重ねるとコピー内容が表示され、スマートフォンでは44pxの押しやすい範囲を確保しています。

- 金額コピー：現在の見積計上額を3桁区切りの数値だけでコピー（例 `150,000`）。円記号や単位は付けません。
- 根拠コピー：現在の設定を使った計算式に、採用額と標準額の差分を付加。例：部品代150,000円・標準7,500円・採用10,000円なら `部品代×5％+2,500（＝部品代6.7％）`。減額なら `-2,500`、同額・未変更なら差額表記なし。
- 消耗資材費・撤去品引取費・養生安全対策費を補正した場合、採用額 ÷ 基本入力の部品代を小数1桁に四捨五入して末尾に併記します（整数比率の末尾 `.0` は省略）。同額・未変更時と部品代0円の場合は併記しません。
- 交換作業費は売価の式だけをコピーし、参考原価は含めません。
- 部品送料・運搬交通費は `1.5人×4,000+20,000` のように内訳をコピーします。
- コピー成功はその行で通知。Clipboardが利用できない場合は、その行に手動選択用の欄を表示します。
- 入力に不正な値がある間はコピーを無効にします。コピー操作による外部通信やデータ保存はありません。

## 保存用サマリー

画面のスクリーンショットではなく、専用確認シートを生成します。基本条件、**変更後の標準設定値**、見積内訳、交換作業費の売価・参考原価、法定福利費の参考原価、標準総額との比較、変更費目の標準→採用・差額・比率・メモを含みます。変更していない費目のメモも別欄に出力します。

- PNG：Canvasで幅2,240pxの白背景画像を生成。内容に応じて高さを調整し、メモを自動折り返しします。端末によってダウンロードできない場合は表示画像の長押し保存を利用できます。
- コピー：同等内容のプレーンテキスト。Clipboard APIを使い、利用不可／権限拒否時には手動コピー欄を表示します。
- 確認シート・画像の出力日時：端末時刻を基に日本時間（Asia/Tokyo）、秒付きで表示。ファイル名は `estimate_YYYYMMDD_HHmmss.png`。

## プライバシー

入力はページのメモリ内のみ。ストレージ、Cookie、データベース、外部API、解析、外部CDN、Webフォントは使用しません。再読み込み・ページ再表示で初期値に戻します。画像・テキスト出力は明示的なボタン操作時のみ端末内で行います。静的配信時にHTML/CSS/JS自体を取得する通信は発生しますが、見積の入力や出力内容は送信しません。CSPでも `connect-src 'none'` を指定しています。

## ドット絵の作業ねこ（任意の飾り）

画面上部のバー右端に、黄色いヘルメット・グレーの毛並み・白い口元とお腹のドット猫を表示します。待機中は指差し確認のポーズをとります。入力中、コピー成功、端数調整、リセット、PNG生成、入力エラーに反応し、30秒操作がないと眠ります。月のボタンでそのページ内だけ非表示にでき、「猫」で再表示します。保存・音・外部通信はありません。OSの「視差効果を減らす」設定では連続アニメーションを停止します。画像・テキスト出力には含めません。

猫は `cat.js` / `cat.css` / `assets/cat-sprites.png` に分離しています。画像は添付のドット絵を参考に生成した透明背景の4ポーズ素材で、配信時も同じサイト内から取得します。画像を読み込めない場合は猫だけを非表示にします。計算エンジンは変更せず、操作の種類のみを通知します。猫追加前のコミットは `0102f39`。戻す場合は猫追加コミットをrevertし、以後の計算変更がある場合は維持してください。

交換作業費と法定福利費の参考原価は見積計上額の下、右側に表示します。計算式はコピーアイコンに隣接する原価欄のツールチップ、および保存用サマリーで確認できます。法定福利費は売価・参考原価それぞれの金額を個別にコピーできます。
