# 見積計算ツール / ESTIMATE

設備工事等の見積を、その場で計算する静的Webアプリです。日本語・PC／スマートフォン対応。実行時の依存パッケージ、ビルド、ログイン、サーバー処理は不要です。

## 起動

`index.html` をブラウザで開いてください。テキストの自動コピーはブラウザによりHTTPSまたはlocalhostが必要です。コピーできない場合は選択用テキスト欄が表示されます。

ローカルHTTPで確認する場合：

```sh
cd /workspace/test
python -m http.server 8000 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:8000` を開きます。公開する場合は `index.html`、`styles.css`、`calc.js`、`portable.js`、`app.js`、`cat.css`、`cat.js` の7ファイルと `assets/cat-sprites.png` を、フォルダー構成を保って静的配置してください。

## 使い方

1. 部品代、作業人員、部品送料を入力します（初期値は0）。
2. 必要な場合だけ標準設定を開いて掛率・単価を変更します。
3. 費目ごとの採用額を入力します。空欄は標準額を使用し、明示的な0は0円を採用します。
4. 任意で100文字までの補正理由・メモを入力します。個人情報や案件識別情報は入力しないでください。
5. 計算結果を確認し、必要な場合のみPNG保存またはテキストコピーを実行します。

基本入力や設定を空欄にすると0として扱います。不正値は個別エラーを表示し、計算への代入値を0として画面を維持します。不正値がある間は出力・プレビューを無効にします。修正後に正しい値から即時再計算します。

## 簡易版のコピー・条件の読み込み

「結果を持ち出す」の **簡易版をコピー** で、基本条件、全掛率・単価、各採用額、メモ、追加項目、諸経費モード、税別総額、出力日時を短いテキストにまとめます。原価の説明や標準比較の詳細は省略します。従来の確認シート・PNG出力も利用できます。

後日、画面上部の **簡易版から計算条件を読み込む** を開き、コピー全文を貼り付けます。「内容を確認」で反映後の金額・設定・固定項目を確認してから「この条件を反映」を押します。確認中は現在の入力を変更しません。形式違い、項目不足・重複、範囲外の値、計算総額の不一致は反映を拒否します。対象は本アプリの `NekoAssist 簡易シート v1` 形式のみで、画像や任意の文章は読み取りません。

- 初期選択の「補正した経費を、採用時の割合で連動させる」は、採用額を指定した消耗資材費・撤去品引取費・養生費の **基本入力の部品代比** と、手動諸経費の **小計比** を引き継ぎます。部品追加後も同じ割合で再計算できます。
- 例えば部品85万円に対して消耗資材費7万円なら、部品170万円で14万円。内部は元の金額の比（分子／分母）を使い、画面に表示する丸めた％を計算に使用しません。金額の精度は既存計算と同じ小数12桁固定小数です。
- 基準額が0円なら比率を作らず固定額で復元します。部品代・交換作業費・送料・追加項目の手動採用額も固定で、プレビューに明記します。採用額が空欄の費目は元の設定率・単価で計算します。
- チェックを外すと元の入力・連動状態をそのまま復元します。既に引継率連動で出力したテキストは、その連動も復元します。諸経費の端数付き自動連動はそのまま維持します。
- 引継率で連動する採用欄には状態を表示します。採用額の手入力で固定、空欄で標準に戻ります。対応する標準設定の率を変更した場合も、引継率を解除して新しい設定率を適用します。一括端数調整は引継率を解除し、従来どおり標準額を採用します。
- メモ・追加名称は引用符をエスケープし、DOMにはテキストとして反映します。簡易版は追加100項目・50,000文字までです。値引計算は試算のため含めません。
- コピー拒否時は手動コピー用欄を表示します。読み込みもすべてブラウザ内で完結し、保存・外部送信はありません。読み込み用テキストもリセット・再読み込みで消えます。テキストを残す場合はユーザー自身で保管してください。

## 計算ルール

内訳およびPNG・テキスト出力の表示順は、部品代 → 交換作業費 → 消耗資材費 → 部品送料・運搬交通費 → 撤去品引取費 → 養生・安全対策費 → 諸経費です。「送料」は「部品送料・運搬交通費」に改称しています（基本入力の部品送料はそのままです）。

- 部品代：基本入力の部品代。
- 消耗資材費・撤去品引取費・養生安全対策費：**基本入力**の部品代 × 対応率（初期値5%、3%、2%）。部品代の採用額を変更しても標準額の基準は変えません。
- 交換作業費（売価）：作業人員 × 売価単価（初期値58,000円／人）。
- 交換作業原価（参考）：同じ作業人員 × 固定原価単価36,000円／人。売価と同じ算定根拠欄に表示し、見積総額には加算しません。採用額の変更によって原価は変化しません。
- 部品送料・運搬交通費：同じ作業人員 × 作業員送料単価（4,000円）＋ 部品送料。
- 小計：6費目の採用額、または空欄の場合は標準額の合計。
- 諸経費：採用小計 × 諸経費率（10%）を標準額とし、採用額で任意に上書きできます。小計には諸経費を含めず、見積総額に採用諸経費を1回だけ加算します。諸経費の行は小計の上に表示します。
- 法定福利費：採用交換作業費 × 法定福利費率（16.315%）、**1円未満切り捨て**。
- 法定福利費原価（参考）：切り捨て済みの法定福利費 × 0.66。参考原価は1円未満を切り捨てて表示し、見積総額には加算しません。交換作業費の採用額・法定福利費率の変更にも追従します。
- 見積金額（税別）：小計 ＋ 諸経費 ＋ 法定福利費。消費税は計算しません。
- 標準見積総額：現在の設定値を使い、採用額を一切反映しない場合の総額。諸経費・福利費も標準額から計算します。
- 部品代比：各費目の計上額 ÷ 基本入力の部品代。分母0の場合は「—（基準額0円）」を表示します。
- 標準との差額が0でない費目を変更一覧に表示します。同額の採用額は変更として数えません。諸経費の手動変更も変更一覧・総補正額に反映します。法定福利費は交換作業費から自動計算します。

金額・単価は小数2桁、作業人員・率は小数3桁を受け付けます。1.5人などの小数人員を、交換作業費・送料・原価に共通で使用します。金額上限は1兆円、作業人員上限は100万、率上限は1,000%です。負数、指数表記、不正なカンマ、上限超過は受け付けません。全角数字は半角に正規化します。フォーカス中はカンマなし、離れると3桁区切り表示になります。

金額計算にはBigIntによる小数12桁の固定小数点を使用します。上記の入力桁数内で、法定福利費・参考原価以外の計算では小数円を丸めず保持・表示します。比率表示だけ四捨五入します（費目標準比1桁、部品代比・総額標準比2桁）。採用入力は小数2桁までです。

## 標準額の端数を一括調整

標準設定の直下にある「標準額の端数を整えて採用」で、標準額から採用額を一括入力できます。

- 100万円以上：1,000円単位で切り捨て（1,552,110 → 1,552,000）。
- 100万円未満：100円単位で切り捨て（155,211 → 155,200、15,521 → 15,500、1,550 → 1,500）。100円未満は0円です。
- 部品代を除く基本5費目を調整後、保持した部品代の計上額を含む小計から諸経費の標準額を再計算し、同じ規則で端数を調整します。諸経費は以降も端数調整付きで自動連動します。法定福利費は調整後の交換作業費から自動再計算します。
- 部品代の基本入力・採用額（空欄・0円を含む）は変更しません。他の費目の入力済み採用額は上書きします。標準設定・基本入力・メモは保持します。繰り返し押しても同じ結果です。
- 基本5費目の一括入力はボタンを押したときだけ実行されます。諸経費は端数調整付きの自動連動に切り替わり、以後も追従します。手入力は可能です。入力エラー時には無効。結果が採用額の上限を超える場合は、変更せず説明を表示します。
- 参考原価はすべて1円未満を切り捨てます（交換作業費・法定福利費）。

## 内訳の表示

主表は費目・算定根拠、標準額、採用額、見積計上額の4列です。計上額を強調し、標準額は控えめに表示します。採用額により差額が生じた行だけ、差額と標準比を表示し、補正理由の欄を自動で開きます。詳細は手動でも開閉できます。部品代比とメモ欄は詳細にまとめています。開閉しても入力済みのメモは保持され、画像・テキスト出力にも含まれます。リセット・再読み込み時は詳細も閉じます。

## 任意項目の追加

諸経費の直上にある「＋ 項目を追加」で費目を追加できます。名称（40文字まで、例：試運転調整費）と金額を入力し、必要なら採用額・メモも利用できます。名称未入力時は「追加項目1」などの仮名称を使用します。「削除」で取り除けます。

追加項目も小計・標準見積総額・現在総額・値引試算に含め、諸経費は追加分を含む小計から自動連動します。手動固定中なら変更確認を表示します。法定福利費の基準は交換作業費です。追加項目に参考原価率は自動設定しません。

追加項目は金額・根拠のコピー、端数調整、画像・テキスト出力に対応します。元の金額を標準額とし、採用額があれば上書きします。名称は文字として処理し、HTMLとして実行しません。保存はせず、全リセット・再読み込みで追加行も消えます。

## 諸経費の自動連動

- 初期状態「自動連動」：現在の採用小計×諸経費率で更新します。
- 端数調整ボタン後「自動連動・端数調整」：他の費目・基本入力・率を変えるたび、諸経費も既存の切り捨て規則で再計算します。単に固定採用額を残す動作ではありません。
- 諸経費の採用額を直接入力すると「手動固定」。入力時の小計・率を記録し、変更されたら確認メッセージを表示します。コピー・保存用サマリーにも現状の固定額と注意を反映します。
- 「自動に戻す」または採用額を空欄にすると、直前の自動モード（通常または端数調整付き）へ戻ります。全リセット・再読み込みで通常の自動連動に戻ります。

この変更直前のコミットは `8b4d554` です。必要なら今回の連動機能だけ取り消せます。

## 値引計算（試算）

見積金額の直下に2つの独立した試算行があります。％入力から値引額（円・万円）と値引後の金額、金額入力から値引率と値引後の金額を計算します。基準は現在の税別見積総額で、採用額変更にも追従します。例：500,000円の5％引き→25,000円（2.5万円）引き・値引後475,000円。30,000円引き→6％・値引後470,000円。

％入力は0〜100％・小数3桁まで、金額は0〜見積金額・小数2桁まで。値引額は小数円も保持し、金額から求める率は小数2桁まで四捨五入します。見積0円のとき、金額からの率は「—」です。空欄は未計算として扱います。2行を合算したり互いに連動させたりしません。試算は内訳・原価・見積総額・保存用サマリーには反映しません。リセット・再読み込みで両方とも消えます。

## 参考原価の表示・コピー

消耗資材費・撤去品引取費・養生安全対策費・諸経費は、見積計上額×62％を参考原価として表示します（利益率＝利益÷売価＝38％）。採用額があればその売価を基準に計算し、1円未満を切り捨てます。例：売価100,000円→参考原価62,000円。参考原価は総額への加算項目ではありません。

交換作業費は作業人員×36,000円、法定福利費は現在の法定福利費×0.66の既存ルールを維持します。計6項目に同じ原価コピーアイコンを設け、クリックすると `62,000` のように単位なしでコピーできます。4費目の原価は画像・テキストの確認シートにも含めます。

## 社内システムへの転記

諸経費を含む7費目それぞれで、金額と算定根拠のすぐ横にコピーアイコンがあります。PCではマウスを重ねるとコピー内容が表示され、スマートフォンでは44pxの押しやすい範囲を確保しています。

- 金額コピー：現在の見積計上額を3桁区切りの数値だけでコピー（例 `150,000`）。円記号や単位は付けません。
- 根拠コピー：現在の設定を使った計算式に、採用額と標準額の差分を付加。例：部品代150,000円・標準7,500円・採用10,000円なら `部品代×5％+2,500（＝部品代6.7％）`。減額なら `-2,500`、同額・未変更なら差額表記なし。
- 消耗資材費・撤去品引取費・養生安全対策費を補正した場合、採用額 ÷ 基本入力の部品代を小数1桁に四捨五入して末尾に併記します（整数比率の末尾 `.0` は省略）。同額・未変更時と部品代0円の場合は併記しません。
- 交換作業費は売価の式だけをコピーし、参考原価は含めません。
- 部品送料・運搬交通費は `1.5人×4,000+20,000` のように内訳をコピーします。
- コピー成功はその行で通知。Clipboardが利用できない場合は、その行に手動選択用の欄を表示します。
- 入力に不正な値がある間はコピーを無効にします。コピー操作による外部通信やデータ保存はありません。

## 保存用サマリー

画面のスクリーンショットではなく、専用確認シートを生成します。基本条件、**変更後の標準設定値**、見積内訳、交換作業費の売価・参考原価、法定福利費の参考原価、標準総額との比較、変更費目の標準→採用・差額・比率・メモを含みます。変更していない費目のメモも別欄に出力します。

- PNG：Canvasで幅2,240pxの白背景画像を生成。内容に応じて高さを調整し、メモを自動折り返しします。端末によってダウンロードできない場合は表示画像の長押し保存を利用できます。
- コピー：同等内容のプレーンテキスト。Clipboard APIを使い、利用不可／権限拒否時には手動コピー欄を表示します。
- 出力日時：端末時刻を基に日本時間（Asia/Tokyo）、秒付きで表示。ファイル名は `estimate_YYYYMMDD_HHmmss.png`。

## プライバシー

入力はページのメモリ内のみ。ストレージ、Cookie、データベース、外部API、解析、外部CDN、Webフォントは使用しません。再読み込み・ページ再表示で初期値に戻します。画像・テキスト出力は明示的なボタン操作時のみ端末内で行います。静的配信時にHTML/CSS/JS自体を取得する通信は発生しますが、見積の入力や出力内容は送信しません。CSPでも `connect-src 'none'` を指定しています。
